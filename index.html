قبل توقّع نموذج تجريبي

هل العقد يعبّر
عن اتفاقك؟

أسئلة تتكيّف مع صفتك ومنشأتك، ومراجع نظامية ظاهرة، ونقاط واضحة للنقاش قبل التوقيع.

عرض تجريبي مساند، لا تدقيق قانوني شامل. لا تدخل معلومات سرية. المصدر النظامي هيئة الخبراء، والربط مرجعي لا اتصال بيانات حي.

1. ملفك التعاقدي

الحجم لا يحدد وحده الصلاحيات. اختيار الشكل لا يغني عن وثائق التمثيل. نطاق فحوص العينات هو تصميم الهوية البصرية.

2. العقد التجريبي

سيناريوهات تجربة سريعة (للعرض والتحكيم)

اختر سيناريو جاهز لتعبئة البيانات وتشغيل الفحص وإظهار النتائج وقائمة النقاش مباشرة بضغطة واحدة.

نتائج العينات معدة مسبقًا. عند تعديل النص أو لصق عقد، تعمل قائمة الأسئلة فقط ولا يدعي النموذج تحليل بنوده.

3. أسئلة مرتبطة بالنظام

مرتبة حسب النوع. افتح «لماذا نسأل؟» لعرض الإطار المرجعي. أرقام المواد نقاط رجوع للنص الرسمي وليست حكمًا بانطباقها تلقائيًا.

4. النتائج والنقاش

الإجابة غير المحسومة تنبيه للمراجعة، وليست مخالفة. الإجابة نعم لا تثبت الامتثال. عدم وجود تنبيه لا يعني سلامة العقد.

المصدر النظامي: هيئة الخبراء بمجلس الوزراء

فتح نظام المعاملات المدنية

الارتباط مرجعي بالنص الرسمي، دون جلب مباشر أو مزامنة تلقائية أو شراكة أو اعتماد من الهيئة. يلزم فحص الأنظمة الخاصة والسياق والوثائق قبل تقرير حكم قانوني.

الخصوصية وحدود النموذج

لا API أو تخزين دائم أو مكتبات خارجية. البيانات في ذاكرة الصفحة، وتفقد عند تحديثها. الملفات المنزلة تبقى بجهازك. فتح المصادر أو الترجمة ينتقل لموقع خارجي. لا تحقق من الهوية أو صلاحية التوقيع، ولا تحليل دلالي للنص الحر أو ترجمة داخلية. الربط بالمواد إرشادي ويحتاج مراجعة مختص عند التطبيق.

قبل توقّع — افهم ما فُحص، وما بقي غير محسوم.

الترجمة · 30 لغة

ترجمة خارجية للاسترشاد، وليست ترجمة قانونية معتمدة. لا إرسال تلقائي.

ينتقل النص في الرابط وقد يظهر بسجل المتصفح. راجع النفي والاستثناءات والأرقام. لا تحدد هذه الخدمة لغة العقد المرجحة.
